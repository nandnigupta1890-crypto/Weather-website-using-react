# Weather App

A simple and user-friendly Weather Application built using React.js and Vite.

## Features

- Search weather by city name
- Displays current temperature
- Shows weather condition
- Displays humidity and other weather information
- Simple and responsive user interface

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
- Weather API
